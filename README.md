# Previsor BTC 5 min

Painel que mostra UP/DOWN para as janelas de 5 minutos do BTC, com chance ao vivo durante a janela, comparação com o preço cobrado no mercado de previsão e placar de simulação.

Abra pelo GitHub Pages: https://luan146.github.io/previsor-btc/

Usa só dados públicos de preço (Binance / Coinbase / Kraken), sem conta, sem carteira. Não é recomendação financeira.
